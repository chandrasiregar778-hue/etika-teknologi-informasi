# etika-teknologi-informasi
Website Etika di Era Teknologi Informasi adalah media belajar tentang etika dan tanggung jawab menggunakan teknologi. Materinya meliputi cyberethics, cyberspace, privasi, keamanan data, berita palsu, dan kejahatan siber. Dilengkapi tampilan modern dan kuis interaktif, website ini mengajak pengunjung menjadi pengguna teknologi yang cerdas dan bijak.
